# 14 课外阅读挂载体系（PairingV2）

`agent-textbook` 的英文课外阅读不是"独立书库"，而是**挂在教材 Unit 边上**、按 7 种教学场景（role）供教师选择。本页说明这套挂载的设计动机、角色定义、打分公式、产出物与已知阻塞点。

## 1. 目标

给每一本课外阅读（当前 27 本）与每一个教材单元（64 个）打分，输出：

- **PairingV2 表**：`(reading_id, section_id, role, match_score, breakdown, reasons)`；
- **catalog 回写**：`catalog.json` 中每本书多 `facets.text_role` 与顶层 `pairs_with_unit`。

教师端可以按 "本单元 + 教学场景" 直接查到对应课外文。

## 2. 7 种挂载角色

| Role | 中文名 | 教学目标 | Lexile Δ 目标 | 字数桶 |
| --- | --- | --- | --- | --- |
| `pre_reading` | 预热文 | 课前三分钟激活主题背景 | −200 ~ −50 | very_short / short |
| `bridge_text` | 桥梁文 | 教材文偏难时过渡 | −100 ~ +100 | short / medium |
| `consolidation` | 巩固文 | 同类文型/技能强化 | −100 ~ +100 | short / medium |
| `extension` | 拓展文 | 拔高，主题纵深或语篇难度上台阶 | +80 ~ +300 | medium / long |
| `compare_contrast` | 对比文 | 同主题不同视角/文化 | −150 ~ +200 | short / medium / long |
| `writing_trigger` | 写作触发文 | 供 Project / Writing 模仿 | −100 ~ +150 | short / medium |
| `culture_window` | 文化窗口 | 跨文化视角拓展 | −100 ~ +200 | short / medium |

完整字段见 [`data/readings/extension_roles.json`](../data/readings/extension_roles.json)。

## 3. 打分公式

```
score = 0.30·topic + 0.25·skill + 0.20·word + 0.15·lexile + 0.10·role_bonus
```

- **topic**：教材 tokens ∩ 课外 `primary_topic`+`secondary_topics` 展开词（`_TOPIC_KEYWORDS` 词表），Jaccard，分母 max(12, |union|)。硬门禁：`topic_score ≥ 0.25`。
- **skill**：教材 `section_text` 命中 `_SKILL_KEYWORDS`（reading_comprehension / writing / critical_thinking 等）后的比例。
- **word**：教材 tokens 覆盖 `covers_words` 前 6 词的比例。
- **lexile**：按 role 的 delta 目标区间线性衰减。
- **role_bonus**：`text_type` + `word_count_bucket` + `grade` 交集。硬门禁：`role_bonus ≥ 0.2`。

阈值 `min_pair = 0.55`，同 `(reading, unit)` 多 role 时保留分差 < 0.10 的并列 role。

## 4. 产出物

| 文件 | 说明 |
| --- | --- |
| `data/readings/pairings.json` | PairingV2 主表 |
| `data/readings/catalog.json` | 回写 `facets.text_role` 与 `pairs_with_unit` |
| `data/readings/_audit_pairings.json` | 当前阻塞点/建议清单（审计快照） |

## 5. 生成流程

```
python tools/pair_extensions.py
```

依赖：
- `data/readings/catalog.json`
- `data/readings/extension_roles.json`
- `data/attrs/section_text.jsonl`（教材单元权威）

输出简报：`units=64 readings=27 pairings=24 by_role={...}`。

## 6. 已知阻塞点（详见 `_audit_pairings.json`）

- **P1（P0 级）**：reading 覆盖 5/27、unit 覆盖 2/64，因 topic 硬门禁过严、`_TOPIC_KEYWORDS` 词表未覆盖 weather/sport/transport/health/science/space 等常见教材主题。
- **P2（P1 级）**：同一 (reading, unit) 出现 3 个 role 并列，教师端不便；建议 `keep_within_delta` 收到 0.03 或改为按 role 唯一。
- **P3（P1 级）**：word 维度基本恒为 0，权重 0.20 无效；建议改双向 Jaccard 或降权。
- **P4（P2 级）**：topic 分母 12 是经验值，未在配置中显式化。

## 7. 前端入口

页面：[`pages/extensions/index.html`](../pages/extensions/index.html) — 按 Unit / Reading / Role 三维筛选 PairingV2。

数据源：`data/readings/pairings.json` + `data/readings/catalog.json`，通过 `pages/extensions/_data.json` 打包（离线可用）。
