## 9. 学科差异化设计（★ 核心）

### 9.1 根本差异：三类任务的「正确性」定义不同

| 任务 | 正确性的定义 | 能否要求"每句有原文依据" |
| --- | --- | --- |
| 语文字词（"爽"的笔顺、组词） | 答案唯一，可查表 | 能（查表即依据） |
| 语文阅读理解 | 答案在课文中 | 能（须定位到段落） |
| 语文习作（作文） | **没有唯一答案**，只有"是否符合习作要求" | **不能**——创作不是引文 |
| 数学解题 | 结论可验算，过程是**推导**出来的 | **不能**——推导步骤无原文出处 |
| 数学概念讲解 | 定义来自教材 | 能 |
| 口算练习 | 程序化生成 + 确定性判分 | 不涉及 |

**这是本项目最容易踩的坑**：若用同一套「每句必须有出处」的 Guard 管所有学科，结果必然是——作文被卡死（每句都要出处）、数学解题被卡死（推导步骤没有出处）、而字词题反而过度设计（本来查表就行，却走了一遍语义检索 + LLM 生成）。

### 9.2 Guard 三模式（关键设计）

| 模式 | 适用 | 校验什么 | 不通过的处理 |
| --- | --- | --- | --- |
| **strict** 事实溯源 | 概念答疑、字词、阅读理解、道法情境题 | 每句能否在**教材原文（core）**中找到依据；教辅与课外不计入依据集 | 删除无依据句；核心结论无依据 → **整条拒答**「教材里没有」 |
| **derivation** 推导有效 | 数学解题、算理说明 | ① 前提与结论有教材依据；② 中间步骤**逻辑有效、无跳步**；③ 可验算的结论必须验算通过 | 标出跳步 → 要求补步；验算不过 → 重算 |
| **rubric** 量规评价 | 习作、开放性表达、口语交际 | 是否符合习作要求清单、年级语言水平、字数/格式/体裁 | 按量规给分项反馈与修改建议；**不溯源、不拒答** |

配套规则：

- **拒答只用于 strict**。孩子问"怎么写这篇作文"，回答"教材里没有"是荒谬的。
- **derivation 的引用是分层的**：`[依据: 三上·数学·P68 例题]` 标注前提与所用规则，`[推导]` 标注推理步骤——让读者一眼分清"哪句是书上说的，哪句是推出来的"。
- **rubric 的量规来自教材**：习作单元的要求清单就是 rubric，不是模型自己编的标准。

**★ 第四维：超纲拦截 `scope_guard`**（来自语文教材本体 docx §7.3，叠加在三模式之上）

| 检查 | 判定 | 处置 |
| --- | --- | --- |
| 知识点是否在当前册范围内 | 超出当前册语文要素 / 数学知识点 | 标为"课外选学"，**不主动讲解**；学生主动问才答，且须说明"这是课外知识，以后会学到" |
| 扩展语料是否超前 | 教辅、奥数内容超前于当前册 | 同上；且**不计入掌握度** |
| 语言难度是否匹配 | 低年级用了中高年级句式、生僻字未注音 | 重写为适龄表达，或补注音 |

理由：小学生"讲超纲"是真实的坑——课文里有排比句不代表三年级该学排比修辞，
教材有鸡兔同笼不代表该把全部变式讲给孩子。**模型越能说，越要有个边界。**

### 9.3 语文设计

三块能力的数据形态、检索、校验完全不同，必须分开设计：

| 能力 | 数据形态 | 检索方式 | 校验 | 特殊设计 |
| --- | --- | --- | --- | --- |
| **字词基础** | 结构化表：识字表 / 写字表 / 词语表 / 多音字 / 近反义词 | **精确查表**（SQLite），**不走语义检索、不调 LLM** | 确定性判对错 | 笔顺、部首、笔画数需字典数据；听写需 TTS（V1） |
| **阅读理解** | 整篇课文 + 课后题 | **整篇注入**（课文几百字，**不切块**） | strict：答案须在课文中定位并给出段落 | 按**阅读策略单元**组织提问：四年级"提问"（针对内容/写法/联系生活）、五年级"提高阅读速度"、六年级"有目的地阅读" |
| **习作（作文）** | 习作要求 + 习作例文 + rubric | 检索本册习作单元要求与例文结构 | **rubric**：对照要求清单逐条评分 | 给**写作支架**（提纲/句式/素材），**不代写整篇** |

语文特有设计点：

- **课文整篇存取是硬要求**。切块会破坏叙事与语境，阅读理解必然答不准。所以 `lesson_texts` 表独立于 chunks。
- **字词表要规则抽取**（教材附录格式规整），准确率要求接近 100%；这是"抽取"不是"生成"，不能让 LLM 编。
- **不代写作文**：直接给整篇范文对孩子有害且无效。设计为「支架 + 片段示范 + 按 rubric 自评 + 修改建议」。
- **习作场景的知识来源组合**（★，见 6.8.5）：**要求来自教材**（习作要素 = rubric，可核对）、
  **示范来自上传的作家作品集**（可引篇名的仿写片段）、**方法来自模型内化知识**（须标注"非教材内容"）。
  三者分工后，"不代写"的底线不变（只给支架 + 片段示范），但示范从"笼统的正确话"变成"可核对的原文片段"——
  这正是教作文时最缺的一环：孩子要的不是"要写生动"，而是"看汪曾祺这句怎么写生动的"。
- **背诵与朗读**：需要原文精确输出（V0 文本，V1 加 TTS）。
- **古诗文**：需注释、译文、作者背景——教材内有注，超出部分要标注来源，否则按 strict 应拒答。

**★ 语文维度清单：docx 的 40 类节点如何落地**

`小学语文教材本体与智能教学Agent设计方案.docx` 定义了 **40 类节点 / 37 类关系 / 12 条公理**
（十层：LV 版本 → L0 骨架 → L1 语言基础 → L2 语文知识 → L3 语文要素 → L4 课标 → L5 教学行为
→ L6 人文 → L7 资源 → L8 评价）。维度确实很多，但**绝大多数是"属性"或"结构化表"，不是图节点**：

| 层次 | 代表节点 | 落地方式（本系统） |
| --- | --- | --- |
| LV 版本 | CurriculumStandard / TextbookEdition / RevisionBatch | **字段**（`version` 已有）；保留双时态字段，**暂不建版本关系图** |
| L0 骨架 | Volume / Unit / Section / Text / Paragraph / Sentence | **目录抽取 + 页级坐标**（目录待抽，见 §8.11.5） |
| L1 语言基础 | Character / Word / SentencePattern / Punctuation | **SQLite 结构化表**（字词表，已有） |
| L2 语文知识 | Genre / RhetoricDevice / DescriptionMethod / ReadingStrategy | **`Text` 的属性**（规则 + LLM，见 `10知识库选型.md` §4.4.1 对齐表） |
| L3 语文要素 | ReadingElement / WritingElement / OralElement / **SpiralLink** | **要素表**（已有 `strategy_unit`，需扩到"要素"层）；SpiralLink 用**跨册统计**实现 |
| L4 课标 | CoreCompetency / **LearningTaskGroup** / StageGoal | **常量表**（学习任务群是 2022 课标固定分类，可预置） |
| L6 人文 | HumanisticTheme / CultureType / Festival | `Text` 属性（LLM 标注） |
| L7 资源 | Author / Resource / **BooklistItem** | `Author` 表已有（**170 位**）；**BooklistItem（快乐读书吧推荐书目）= 挂载课外书的现成锚点** |
| L8 评价 | Exercise / **ErrorPronePoint** / StudentProfile | Exercise 已有；**ErrorPronePoint（易错点库）待加**；Profile 见 §8.11 |

> **关键结论：维度多 ≠ 关系多。**
> 40 类节点里约 25 个是属性、8 个是结构化表，真正需要"关系边"的很少。
> 因此与 `10知识库选型.md` §4.3「不建重型知识图谱」**并不冲突**——
> **docx 的"维度多"正是 §4.4「属性要丰富」所主张的，只是用属性表 + 结构化表 + 元数据过滤来实现，
> 而不是建 37 类三元组关系。**

**docx 有而本系统待补的四项**（价值明确，成本可控，按序补）：

1. **BooklistItem**（教材"快乐读书吧"推荐书目）→ 扩展书籍的**官方挂载锚点**；
2. **ErrorPronePoint**（易错点库）→ 字词/知识点的常见错误，直接提升归因与出题；
3. **LearningTaskGroup**（学习任务群）→ 2022 课标的顶层分类，常量表即可；
4. **SpiralLink**（要素螺旋上升）→ 用"同一要素在哪些册出现"的统计实现，**不需要关系边**。

**待验证，不预设排除**：版本维度的 9 类关系当前单版本用不上，**是否建取决于 `10知识库选型.md` §4.3 的图谱试点结果**，
现阶段只留字段；L5 教学行为层属 Agent 层，不进本体；命名图隔离与引用计数装卸机制是服务端多用户工程，
本场景暂不需要（若未来多用户再议）。

> **原则**：设计阶段不做"永久排除"的技术决策，只做**当前默认 + 决策门**——
> 默认可以偏向轻量，但必须写清"什么证据会让我改变选择"。

### 9.4 数学设计

| 能力 | 特点 | 检索 | 校验 |
| --- | --- | --- | --- |
| **概念讲解** | 教材定义 + 例题 | 语义检索 | strict |
| **算理（为什么这样算）** | 如"为什么数位要对齐"、"为什么除以分数等于乘倒数" | 检索定义 + 例题 | strict + 分步 |
| **解题** | 分步推理链 | 检索**同类例题**作解法参照 | **derivation** |
| **口算/计算练习** | 程序化生成，**不需要检索** | 无 | 确定性判题，**不调 LLM** |
| **错题归因** | 错因分类 | 检索对应知识点 | 归因到 `kp_id` + `MistakeType` |

数学特有设计点：

**★ 主线：数学思维的培养（知识点只是载体，思维才是目的）**

语文有"语文要素"（提问 / 提高阅读速度 / 有目的地阅读…）作组织主线，数学的对标物是
**2022 版课标的核心素养表现**（数感、量感、符号意识、运算能力、几何直观、空间观念、推理意识、
数据意识、模型意识、应用意识、创新意识）——对应"三会"：
会用**数学的眼光**观察、会用**数学的思维**思考、会用**数学的语言**表达。

这不是我们外加的框架——**教材自己就在这么教**（实测）：

| 教材内置的思维框架 | 实证 |
| --- | --- |
| 解题四步 | **阅读理解 → 分析解答 → 回顾反思**（三上 P16、六上 P43、四下 P122…） |
| 探究循环 | **探究 → 尝试 → 反思 → 挑战自我 → "生活中还有哪些应用"**（四下鸡兔同笼、六下鸽巢） |
| 教材原话 | 六下 P103："**数学思想和方法可以帮助我们有条理地思考，简便地解决问题**" |
| 思维方法词频 | 转化 **32** > 画图 30 > 分类 24 > 验证 22 > 线段图 18 > 估算 14 > 有序 9 > 列表 7 |

→ 因此数学侧的原则：**流程照抄教材（可核对），思维标签从教材词频抽（不是模型编的），
奥数只是高难度素材、从属于这条主线。**

**思维方法标签 `thinking_tags`**（从教材抽取，用于检索、讲解与归因）：
`转化` `画图/数形结合` `分类` `验证验算` `估算` `有序枚举` `列表` `假设` `逆推` `建模` `类比` `找规律`
——**"转化"出现 32 次居首**（如"多位数乘一位数都可以转化为表内乘法"），它就是小学数学思维的骨架：
把没学过的变成学过的。

**落到 Agent 行为**：

| 环节 | 做法 |
| --- | --- |
| 讲解 / 解题 | 固定按教材四步出（阅读理解 → 分析解答 → 回顾反思），**流程不自由发挥** |
| 讲完后 | 点一句"这题练的是○○"——"把没学过的变成学过的，这就是转化" |
| 错因归因 | 不止"进位错了"，要指出**思维断点**：没建成模型？转化方向错？枚举无序？没验算？ |
| 掌握度 | **双维度**：知识点 × 思维方法——"算得准但不会建模"要能被看出来 |
| 提问策略 | 像语文按阅读策略提问那样，数学按思维方法问："换个数字方法还行吗"（推广）、"这题和昨天的像在哪"（类比）、"能画个图吗"（数形结合） |

> **与语文的对称**：语文主线是**阅读策略**（按策略单元组织提问），数学主线是**思维方法**（按数学思想组织解题与提问）。
> 两者都锚在教材上，都不是模型自由发挥——这是本项目"教材为锚"在学科侧的第二次落地。

**★★ 必须守住的主次**：思维是主线，奥数是素材。
同一道鸡兔同笼：用它讲"假设法"是思维课；刷十道变式就只是刷题。
**如果只能在两者间选一个，选思维。**

- **解题必须分步输出**，每步标注依据类型：

  ```
  ① 25×4 = 100          [推导]
  ② 100÷5 = 20          [推导]
  ③ 验算：20×5÷4 = 25 ✓  [验算]
  依据：四则运算顺序 [依据: 三上·数学·P68 例题]
  ```

- **错因分类驱动复习路径**（数学 Agent 最有价值的输出）：

  | 错因 | **思维断点**（★ 归因要到此为止） | 复习动作 |
  | --- | --- | --- |
  | 概念性错误 | 没建成模型（实际问题 → 数学问题这一步断了） | 回看对应例题与定义（strict 讲解） + 补"建模"示范 |
  | 计算失误 | 程序性熟练度（非思维问题，**不归因到思维**） | 推送同型口算练习（`gen_mental_math`） |
  | 审题偏差 | 没抓住数量关系（阅读理解这一步断了） | 推送同类题做审题训练（圈关键词 + 画关系图） |
  | 单位与格式错误 | 规范意识 | 针对性格式提醒 + 少量练习 |
  | 步骤缺失 | 跳步（推导链断） | 要求写出完整步骤并逐步批改 |
  | **思路全无**（新增） | 转化方向错 / 枚举无序 / 不会画图 | 不给答案，先给"脚手架问题"："能画图吗？""换成学过的样子呢？" |

  归因的价值不在分类本身，而在**复习动作能否精确到思维方法**——
  "计算失误"推口算，"没建成模型"则要补建模示范，两者完全不同。

- **判分用规则，解释用 LLM**：答案对不对是确定的（字符串/数值比对），不该让 LLM 掷骰子；LLM 只负责解释错因与给建议。
- **一题多解**：同一题生成 2–3 种解法再对比（多轮 Teacher 生成 + 对比），培养思维灵活性——这是数学"思维训练"的核心，而非刷题。
- **符号保真**：解析阶段必须保住数学符号；数学册优先文本层，OCR 册须人工抽检公式页（错误符号会直接教错孩子）。
- **动画优先于文字**（★）：数学的认知对象是**过程**（怎么分、怎么变、怎么推）。讲"除以分数等于乘倒数"用文字要 200 字且孩子仍懵，
  用"2 个饼能切出几个半块"的动画 3 秒就懂。因此数学 Profile 的展示形态默认 `animation`，讲解类任务先出动画再配文字。
- **动画必须参数化、模板化**：数值取自教材例题（`MathProblem`），图形由模板渲染，**不让模型自由画**——
  画错的分数动画（切错份数）比不画更糟。这是数学侧的硬要求，与"不编造"同源。
- **游戏化练习不调 LLM**：口算与计算题由 `gen_mental_math` 程序化生成，前端加计时/连击/关卡/即时反馈，
  **0 次 LLM 调用**；游戏化与错因归因绑定（错了推同型题再战），单局 3–5 分钟，避免喧宾夺主。
- **教材插图描述是动画的素材基础**：VLM 已把教材里的几何图、线段图、统计图转成 `[图N] 描述` 入库（§6.4），
  这些描述可直接作为动画脚本的结构来源——不用重新识别图形。

- **扩展语料：教辅 + 奥数（★，从属于上面的思维主线）**：教材一个知识点只有 2–3 道例题、练习量不足，教辅补梯度，
  奥数提供高难度素材——但它们都是**素材**，"练哪种思维"才是目的。而**思维训练本身就在教材里**（实测锚点）：

  | 教材锚点 | 位置 |
  | --- | --- |
  | 「数学广角」 | 三/四/五/六年级共 **11 处** |
  | 鸡兔同笼 | 四年级 P122–123（就在数学广角单元） |
  | 植树问题 | 五年级 P120 |
  | 抽屉原理 | 六年级 P73 |
  | 找规律 | 二/三/四/六年级共 7 处 |
  | 思考题 | 一至五年级 14 处 |
  | 你知道吗 / 生活中的数学 | 44 / 17 处 |

  → **奥数不是教材之外的外来体系，而是「数学广角 / 思考题」的加深与变式。**
  因此扩展只挂在教材已有的思维主题上，**不引入教材完全没有的专题**（三年级不讲数论）。

- **奥数层的门槛（比语文 L3 更严）**：

  | 规则 | 说明 |
  | --- | --- |
  | 默认**不主动推送** | 课内内容未掌握前不出现 |
  | 触发条件三选一 | 课内掌握度达标 / 学生主动要求 / 拓展环节 |
  | 必须标注 | "这是拓展题，课内不要求" |
  | 解法优先级 | **教材解法优先**；奥数解法（假设法、数形结合、方程）标为"另一种思路"，不得贬低教材方法 |
  | 不计入掌握度 | 拓展题做错**不标记薄弱点**——超纲题不会 ≠ 课内不会 |

- **挫败感控制**：奥数题失败率天然高，连续卡住 2 次即降级给台阶（"这题确实难，我们先回到课本这种类型"），
  绝不让孩子在超纲题上反复受挫。

### 9.5 英语设计

**痛点（学校与家庭的真实缺口）**

| 痛点 | 现状 |
| --- | --- |
| **开口机会** | 40 人班，一节课孩子平均开口不到 1 分钟 → 哑巴英语是结构性的 |
| **发音** | 家长不敢教（怕自己口音带偏），学校纠不过来 |
| **语境** | 学了句型没处用，单词孤立背、背完就忘 |
| **资源** | 分级读物贵、选书难、读了没人对话 |

**竞品格局**

| 竞品 | 做法 | 弱点（我们的机会） |
| --- | --- | --- |
| Duolingo | 游戏化自学体系 | 强在游戏化；**与课本脱节**，学完不一定会考 |
| Speak / 各类 AI 外教 | 自由语音对话 | 强在开口量；**词汇不受控**，会拿初中词跟三年级孩子聊 |
| 斑马 / 叽里呱啦 | 启蒙动画跟读 | 只覆盖低幼，三年级起断层 |
| 讯飞 / 有道学习机 | 教材点读 + 发音评测 | 已做教材同步（卖得动 = 需求被验证）；**硬件绑定 + 订阅 + 数据上传** |
| RAZ / 牛津树 | 分级阅读 | 内容好但**无交互** |

→ **"教材同步"已是验证过的刚需，但没人做到"教材词汇范围锁定的自由对话"。**

**★ 差异化：词汇与句型范围锁定（英语版 scope_guard）**

AI 生成的任何英语句子，**只能用当前册已学词汇与句型**——生成后做词表校验，超纲词即重写。

理由不是洁癖，是有效性：**孩子读不懂的对话等于没练**。这正是通用 AI 陪练的真实缺陷——
它很流利，但用的是孩子没学过的词，练 10 分钟孩子只记住了自己听不懂。

**实证锚点**：库内英语 12 册 / 1136 页（三至六年级，三年级起点）。
`Read and write` **56 处**、`Story time` 11 处、`Let's talk` 4 处
→ 教材重心在**读写与故事**，**对话板块偏少**。因此对话题材以 `Story time` / `Let's talk` 为骨架，
AI 在教材句型范围内扩展——**不能凭空造场景**。

| 能力 | 做法 | 校验 |
| --- | --- | --- |
| 词汇 | 教材词表**精确查表**（SQLite），不走语义检索、不调 LLM | 确定性 |
| 句型 | 本册句型表；对话生成后**词表 + 句型双重校验** | 范围锁定 |
| **角色扮演** | AI 演教材场景里的角色（购物 / 问路 / 自我介绍），孩子用本课句型完成任务 | strict：句型须出自教材 |
| 跟读与发音 | TTS 示范 + ASR 评分（V1，需语音栈） | 音素级反馈 |
| 听写 | 与语文字词同构（`check_answer` 复用） | 确定性 |

**依赖与风险**：TTS/ASR 质量决定体验上限（V1 引入：Whisper + Piper/ChatTTS）；
本地运行的额外价值是**孩子的语音不出本机**——竞品全部上传云端。

### 9.6 科学设计

**痛点**

| 痛点 | 现状 |
| --- | --- |
| **开课率** | 副科被语数占用，不少学校科学课名存实亡 |
| **实验** | 器材缺、课时紧、有安全风险 → 教材 174 处实验，孩子基本没做过 |
| **家长** | 答不了"为什么"，或答错 |
| **断层** | 初中物理/化学/生物的先修空缺 |

**竞品格局**

| 竞品 | 做法 | 弱点（我们的机会） |
| --- | --- | --- |
| **PhET**（科罗拉多大学） | 免费仿真实验（电路 / 光 / 力） | **最佳参考**；但全英文、**不按中国教材组织** |
| 科普短视频（抖音 / B站） | 看实验 | **只看不做**，不产生探究能力 |
| 百科 / AI 问答 | 答"为什么" | **会编造**；且直接给答案，恰恰破坏探究 |
| 实验盒子 | 卖器材 | 家长懒得弄，做完即弃 |

→ **科普内容是红海，"教材同步的探究工具"是蓝海。**

**★ 实证骨架（教科版 12 册 / 1015 页，一至六年级全覆盖）**

| 教材词频 | 次数 | | 教材词频 | 次数 |
| --- | --- | --- | --- | --- |
| **观察** | **336** | | 研讨 | 130 |
| **记录** | **267** | | 拓展 | 124 |
| 实验 | 174 | | 材料 | 100 |
| 制作 | 157 | | **安全** | **36** |

两个反直觉的结论：

1. **教材的重心是"观察与记录"（336 / 267），不是知识问答。**
   这直接推翻"科学 AI = 回答孩子为什么"的产品直觉——**教材要的是带孩子走一遍探究过程。**
2. **教材自带安全提示 36 处**——安全不是我们外加的约束，教材本身就在教。

| 能力 | 做法 |
| --- | --- |
| 探究引导 | 按教材流程：**观察 → 猜想 → 设计方案 → 记录 → 研讨 → 拓展**；**先问"你观察到了什么"，再谈结论** |
| 虚拟实验 | 参数化仿真（PhET 式），**绑定教材实验页**（不是通用实验），数值取自教材 |
| 事实问答 | strict 溯源；**教材的简化说法按教材讲**，并标注"以后你会学到更精确的解释" |
| **安全** | Guard 硬规则：涉及火 / 电 / 药品 / 刀具 / 高处 → 必须输出成人陪同提示（依据即教材 36 处） |
| 素材 | VLM 已把实验装置图转成描述入库（§6.4），可直接作为仿真脚本的结构来源 |

**为什么坚持不给直接答案**：孩子问"天为什么是蓝的"，直接讲瑞利散射是科普（短视频做得更好）；
教材的方式是先观察、再猜想、再验证。**我们的价值在后者，给答案反而是伤害。**

### 9.7 道德与法治设计

| 项 | 内容 |
| --- | --- |
| 实证 | 14 册 / 1170 页；情境 25 处、讨论 28 处 |
| 竞品 | **几乎无人做**（价值观内容敏感、难商业化）→ 蓝海，但风险最高 |
| 设计 | 情境讨论式：给教材情境，引导孩子思考"你会怎么做、为什么" |
| Guard | **全科最严**：价值观内容**不许模型自由发挥**，答案须回到教材观点（strict 溯源） |
| 开放题 | 用 rubric 引导思考，但**必须给出教材立场**；不做价值相对化的开放辩论（与 §2「不借鉴 AI 圆桌辩论」同源） |
| 原则 | **宁可少答，不可答偏** |

> **学科的锚定基础设施**（先有锚，再谈智能——本项目方法的第四次复制）：
> 语文字词表 / 数学思维标签 / **英语词汇句型表** / **科学实验清单（含材料与安全）** / 道法情境条目。
> 每进入一个新学科，第一件事都是**规则抽取这张表**，而不是先想 Agent 怎么答。

### 9.8 架构落地：学科 Profile 参数化

**不为每个学科写一套 Agent**，而是同一套 Agent + 学科 Profile：

```python
@dataclass
class SubjectProfile:
    subject: str
    capabilities: dict[str, Capability]   # 字词 / 阅读 / 习作 / 解题 / 口算 ...
    # 每个能力声明：检索方式、Guard 模式、挂载工具、输出模板
    retrieval_default: Literal["lookup", "semantic", "whole_text"]
    guard_mode: dict[str, Literal["strict", "derivation", "rubric"]]
    tools: list[str]
    render_forms: dict[str, list[str]]    # ★ 能力 → 允许的展示形态（见 8.8.3）
    #   语文·讲解: [text, audio, guided, pptx]       朗读与引导优先
    #   数学·讲解: [animation, text, guided]          动画优先
    #   数学·练习: [game, text]                       游戏化，0 次 LLM
    output_templates: dict[str, str]      # 讲解 / 解题 / 习作的输出骨架
    eval_sets: dict[str, str]             # 学科 × 能力的评测集
    parse_hooks: list[str]                # 该学科在 parse 阶段的额外抽取
```

Router 输出 `(subject, capability, scope)` → 加载 Profile → 选 pipeline + Guard 模式 + 工具集 + 输出模板。

新增学科 = 新增一个 Profile 文件，不动 Agent 主体。

### 9.9 学科差异化对前序阶段的反向影响

这不是只在 Agent 层的事，会一路反向影响 parse / index / eval：

| 阶段 | 语文 | 数学 | 英语 | 科学 |
| --- | --- | --- | --- | --- |
| **parse** | 抽取识字表/写字表/词语表；课文按段完整保留、不做清洗 | 符号与公式保真；区分例题/做一做/练习/复习题 | 抽取**词汇表与句型表**（附录格式规整）；保留 `Let's talk` / `Story time` 对话原文 | 抽取**实验清单**（实验/材料/安全）；保留探究流程步骤 |
| **index** | 课文整篇另存**不切块**；字词进 SQLite 表走精确匹配 | 题目+解法整体成块，按 `type` 与 `kp_id` 索引 | 词汇与句型进 SQLite 表走**精确匹配**（支撑范围校验） | 实验按单元索引，装置图描述单独存（仿真素材） |
| **eval** | 字词确定性评测、阅读理解定位准确率、习作 rubric 评分一致性 | 解题步骤完整性、验算正确率、错因归因准确率 | **生成句子的超纲词率**（目标 0）；词汇查表准确率 ≥ 99% | 探究流程完整性；**安全提示召回率 100%**（漏一条即不合格） |
| **工具** | `lookup_word` / `read_lesson` / `get_rubric` | `lookup_problem` / `gen_mental_math` / `check_answer` | `lookup_word` / `check_vocab_scope` / `roleplay` | `list_experiments` / `simulate` / `check_safety` |

> **安全提示召回率 100%** 是唯一一个"零容忍"指标：科学实验涉及火、电、药品、刀具，
> 漏一次提示的后果不是体验差，是孩子受伤。
