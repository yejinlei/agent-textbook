# 01 教材下载：原理与使用

> 本文只讲**如何把教材从国家中小学智慧教育平台下载到本地 `books/`**，以及背后的抓取原理。
> 工程定位是「用 Agent 辅助小学生学习」，完整链路是
> **采集 → 解析 → 入库 → 应用**，本文覆盖第一步（`src/agent_textbook/collect/`）。
> 第二步「把 PDF 变成结构化文本」见 `02教材提取方案.md`。

---

## 1. 数据来源与参考实现

| 项 | 值 |
| --- | --- |
| 站点 | [国家中小学智慧教育平台 · 电子课本](https://basic.smartedu.cn/tchMaterial/) |
| 目录/详情静态域 | `s-file-1.ykt.cbern.com.cn` |
| PDF 私有 CDN | `r1 / r2 / r3-ndr-private.ykt.cbern.com.cn` |
| 解析方法参考 | [happycola233/tchMaterial-parser](https://github.com/happycola233/tchMaterial-parser)（MIT） |

本项目按其思路实现了**无 GUI 的命令行版本**，对应三个模块：

- `collect/net.py` —— HTTP 层：限速、签名、镜像、流式落盘
- `collect/catalog.py` —— 拉取层级与书目、按学段/学科/版本/年级筛选
- `collect/downloader.py` —— 解析详情拿直链、并发下载、维护清单

## 2. 抓取原理

### 2.1 三步拿到 PDF 直链

| 步骤 | 接口 | 作用 |
| --- | --- | --- |
| ① 层级定义 | `GET {SFILE}/tags/tch_material_tag.json` | 学段 → 学科 → 版本 → 年级的 `tag_id → 名称` 映射 |
| ② 书目表 | `GET {SFILE}/resources/tch_material/version/data_version.json` → 取其中的 `urls` | 每个 URL 是一批书目 JSON（当前 4 个分片，共 2925 条：小学 1034、初中 769、高中 516、小学五·四 125、初中五·四 176、特殊教育 305）。每条含 `id`、`title`、`tag_paths` |
| ③ 详情 | `GET https://s-file-1.ykt.cbern.com.cn/zxx/ndrv2/resources/tch_material/details/{contentId}.json` | 返回 `title`、`global_title`、`ti_items[]` |

`tag_paths` 是形如 `tagA/tagB/tagC/...` 的 id 串，用 ① 的层级树逐段翻译，得到可读路径
`电子教材 / 小学 / 数学 / 人教版 / 一年级`，存进 `catalog.jsonl` 的 `path` 字段。

### 2.2 从详情里挑源文件

`ti_items[]` 是该资源的多个文件条目，挑选规则（`downloader._pick_source`）：

1. 只要 `ti_is_source_file = true`；
2. 跳过 `ti_format = folder`（目录节点）；
3. 取 `ti_storage`，形如 `cs_path:${ref-path}/edu_product/.../xx.pdf`，
   把前缀替换成 `https://r1-ndr-private.ykt.cbern.com.cn` 得到直链；
4. `ti_storage` 为空时退回 `ti_storages[]` 里第一个非空值；
5. `ti_size` 作为 `expected_size`，下载后用它校验文件完整性。

书名优先取 `global_title["zh-CN"]`，缺失时退回 `title` / `id`。

### 2.3 分类解析 `catalog.classify()`

把 `path` 解析成 `(学段, 学科, 版本, 年级)`。平台路径长度不统一：

- 小学：长 5 → `学段 / 学科 / 版本 / 年级`
- 高中：长 4 → `学段 / 学科 / 版本`（无年级层）
- 少数条目（如信息科技）无版本层

判据是「末段是否像年级」（含"年级"、"全一册"，或是"一二三四五六"），据此决定末段归版本还是年级。

### 2.4 鉴权：X-ND-AUTH

私有 CDN 校验请求头 `X-ND-AUTH`，签名原文（`net.build_nd_auth`）：

```
{nonce}\n{METHOD}\n{解码后的 path}[?query]\n{hostname}\n
```

- `mac = Base64(HMAC-SHA256(mac_key, 签名原文))`
- `nonce = (毫秒时间戳 + diff) : 8位随机字符`（字符集 `0-9A-Z`）
- 每个 URL 独立现算签名，不做复用

**匿名可用**：没有凭据时发占位头 `MAC id="0",nonce="0",mac="0"`，绝大多数教材可以直接下。

**需要登录的资源**：部分资源（体育与健康、部分信息科技）详情接口返回 403。
此时把控制台取到的 JSON 存为 `data/token.json`：

```json
{ "access_token": "xxx", "mac_key": "xxx", "diff": 0 }
```

取法：登录 [auth.smartedu.cn](https://auth.smartedu.cn/uias/login) → F12 控制台 →
粘贴参考项目 README 里的取凭据脚本 → 复制输出的 JSON。
有 `mac_key` 时程序自动切换到真实签名（`fetch` 会打印"已载入登录凭据"）。

### 2.5 下载与稳定性策略

| 策略 | 实现 | 原因 |
| --- | --- | --- |
| 全局限速 | `MIN_REQUEST_INTERVAL = 0.2s`，加锁串行化 | 避免触发平台限流 |
| 400 处理 | 退避 1s → 3s 后**重新签名重试同一地址**；若这次带 `Range` 续传，则丢弃 `.part` 从头下 | 该 CDN 对带 `Range` 的请求回 `InvalidArgument`，不丢分片会陷入死循环 |
| 401/403 | 立即判定为鉴权问题，不再重试 | 重试无意义，提示补凭据 |
| 镜像 | 每轮依次尝试 `r1 → r2 → r3`，最多 3 轮（共 ≤9 次请求） | 单节点故障时兜底 |
| 断点续传 | 先写 `.part`，下次带 `Range` 续写；收到 206 追加，收到 200 重头写 | 扫描版单册 100–240MB，连接中断很常见 |
| 大小校验 | 与 `expected_size` 不符则保留 `.part`，下一轮续传补齐 | 防止把截断文件当成品 |
| 原子落盘 | `.part` → `os.replace` 成正式文件 | 中断不留残缺文件 |
| 已有跳过 | 目标存在且大小相符直接标记 ok | 命令可反复重跑 |
| 文件名净化 | `\ / : * ? " < > \|` 转全角，去控制字符，避开 `CON/PRN/COM1` 等保留名 | Windows 文件系统限制 |

## 3. 产物与清单

```
books/                              # --out 指定，默认仓库根 books/
└─ 浙江杭州/                         # --region，教材选用以地区为单位
   └─ 小学/
      └─ <学科>/<版本>/<年级>/<书名>.pdf
data/
├─ catalog.jsonl      平台全量书目（2925 条）：id / title / path / preview_url
├─ downloads.jsonl    下载清单（本项目当前 109 条）
└─ token.json         登录凭据（可选，勿提交）
logs/                 运行日志
```

`downloads.jsonl` 每行一条，是**跨阶段的元数据契约**：

| 字段 | 说明 |
| --- | --- |
| `id` | 平台 contentId，全程唯一键 |
| `title` / `subject` / `version` / `grade` / `stage` / `region` | 分类元数据 |
| `preview_url` | 平台在线预览页，用于人工核对是不是想要的那一本 |
| `url` / `format` / `expected_size` | PDF 直链、格式、声明大小 |
| `path` | 相对 `books/` 的存放路径 |
| `status` | `pending` 待下载 / `ok` 已完成 / `failed` 失败 |
| `reason` | 失败原因（HTTP 状态、异常、无源文件等） |
| `size` | 落盘实际字节数 |

清单按 `id` 合并，**已 `ok` 的记录不会被重新解析降级**；改目录布局请用 `organize` 统一搬迁（会同步更新 `path`），不要手工移动。

## 4. 脚本使用

### 4.1 环境

```powershell
cd d:/src/agent-textbook
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt   # 仅 requests>=2.28
$env:PYTHONIOENCODING = 'utf-8'                                 # Windows 控制台中文
```

`src/` 已加入 `.venv` 的搜索路径，因此可以直接 `python -m agent_textbook`；换环境时用 `PYTHONPATH=src`。

### 4.2 子命令

| 命令 | 作用 | 网络 | 说明 |
| --- | --- | --- | --- |
| `catalog` | 拉取平台全量书目 → `data/catalog.jsonl` | 是 | 只需跑一次；换机器或目录更新后重跑 |
| `list` | 按条件筛选并**打印命中统计** | 否 | 先看命中对不对，再决定是否下载 |
| `fetch` | 解析详情拿直链 + 下载 | 是 | 主力命令；`--dry-run` 只解析不下载 |
| `retry` | 只重跑清单里 `status != ok` 且有 `url` 的条目 | 是 | 限流/网络抖动后补漏 |
| `sync` | 按磁盘已有文件回填清单状态 | 否 | 手工拷过文件、或清单丢失时重建 |
| `organize` | 搬迁到 `<地区>/<学段>/<学科>/<版本>/<年级>/` 布局并更新 `path` | 否 | 改目录结构时用 |
| `status` | 打印各状态计数、已下载体积、失败明细 | 否 | 日常看进度 |

全局参数（放在子命令前或后均可）：`--out`（教材目录，默认 `books/`）、
`--region`（地区层目录名，默认 `浙江杭州`）、`--token`（凭据路径，默认 `data/token.json`）。

### 4.3 筛选参数（`list` / `fetch`）

| 参数 | 说明 |
| --- | --- |
| `--preset hangzhou` | 版本预设，取 `config.VERSION_PRESETS` 里的地区版本对照表 |
| `--stage 小学` | 学段，逗号分隔；**不传则取预设内的全部学段** |
| `--subject` / `--version` / `--grade` | 逗号分隔、子串模糊匹配 |
| `--include-teacher` | 含教师用书（默认排除） |
| `--include-wusi` | 含五·四学制（默认排除） |
| `--limit N` | 只取前 N 条，调试用 |
| `--workers N` | 并发数，默认 3，建议 ≤4（过高会触发 400） |
| `--dry-run` | 只解析直链写清单，并打印预计体积 |

匹配逻辑（`catalog.select_rows`）：先用学段过滤，再依次套学科、年级、预设版本。
预设里版本写 `*` 表示**不限版本**（如信息科技）。传了 `--preset` 时 `--version` 不生效。

### 4.4 典型流程

**首次全量下载杭州小学教材**

```powershell
.\.venv\Scripts\python.exe -m agent_textbook catalog
.\.venv\Scripts\python.exe -m agent_textbook list --preset hangzhou --stage 小学
.\.venv\Scripts\python.exe -m agent_textbook fetch --preset hangzhou --stage 小学 --workers 3
```

**先估算体积再决定**

```powershell
.\.venv\Scripts\python.exe -m agent_textbook fetch --preset hangzhou --stage 小学 --dry-run
# 输出：解析完成：可取文件 N，失败 M，预计体积 X.XX GB
```

**中断后续跑**（三种方式，任选）

```powershell
.\.venv\Scripts\python.exe -m agent_textbook fetch --preset hangzhou --stage 小学   # 重跑，已完成的自动跳过
.\.venv\Scripts\python.exe -m agent_textbook retry --workers 2                     # 只补失败项
.\.venv\Scripts\python.exe -m agent_textbook sync                                  # 按磁盘已有文件回填清单
```

**补登录凭据后重下 403 资源**

```powershell
# 写入 data/token.json 后
.\.venv\Scripts\python.exe -m agent_textbook fetch --preset hangzhou --stage 小学
```

**单学科 / 单年级补漏**

```powershell
.\.venv\Scripts\python.exe -m agent_textbook fetch --preset hangzhou --stage 小学 --subject 数学 --grade 三年级
```

## 7. 常见问题

- **HTTP 403**：需要登录凭据。按 2.4 写入 `data/token.json` 后重跑 `fetch`。凭据有有效期，过期需重取。
- **HTTP 400**：多为私有 CDN 突发限流。等几分钟后 `retry --workers 1`；若曾留下 `.part`，程序会自动丢弃分片从头下（该 CDN 不接受 `Range` 续传）。
- **"详情中没有可下载的源文件"**：该条目在平台上没有开放 PDF（如部分信息科技课程指南），只能换来源。
- **磁盘不够**：`fetch --dry-run` 先估体积。实测小学单册约 20–30MB，美术/科学等扫描版可达 140–240MB。注意 Windows 删除默认进回收站，需清空回收站才真正释放空间。
- **想核对是不是想要的那一本**：用清单里的 `preview_url` 在浏览器打开，或看 `path` 字段的分类。
- **想加 PDF 书签**：详情里 `ti_file_flag = ebook_mapping` 的映射文件 + `trees/{ebook_id}.json` 章节树可据此生成书签（参考项目已实现，本项目暂未接入）。
- **合规**：教材版权归各出版社所有，下载内容仅供个人学习使用，请勿分发或商用。
