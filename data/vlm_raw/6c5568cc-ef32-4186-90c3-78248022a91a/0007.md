临习指导
[图1] 描述：图中画了一个戴眼镜、穿红色背心的卡通女孩，位于“临习指导”标题右侧，作为临习指导的标识。
不同形体结构的字组合方式不同，各自有不同的结构规律。
| 汉字 | 结构分析 |
|------|----------|
| 施 | “施”字左右靠紧，撇、钩向左右伸。 |
| 徵（征） | “徵（征）”字中间收紧，左右两部分向外伸展。 |
| 童 | “童”字上下两部分重心相对，上点与下竖在一条直线上。 |
| 常 | “常”字中间小而收紧，上部分向左右伸展，下部分竖下伸。 |
| 圆（圓） | “圆（圓）”字外框左短右长，内部上下靠紧，左右留空，虚实得宜。 |
| 座 | “座”字中的“坐”以竖为中心，左右对称，竖上下贯穿，“人”分列左右。 |
| 四 | “四”字外框形扁，内部笔画少而空疏。 |
| 或 | “或”字右上包左下，上收下放，钩画向右下伸，被包围部分靠紧斜钩。 |
